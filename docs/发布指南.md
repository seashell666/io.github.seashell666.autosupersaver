## 二、需要上传的文件

仓库内共 22 个文本文件（源码、构建脚本、文档），已在本地 git 提交完成。若由 GitHub 网页或连接器逐个创建，必须保证路径与内容一致，尤其是：

```
app/src/main/resources/META-INF/xposed/module.prop
app/src/main/resources/META-INF/xposed/scope.list
app/src/main/resources/META-INF/xposed/java_init.list
```

这三个文件决定 Vector 能否识别模块。`module.prop` 与 `scope.list` 必须是 **LF 换行**（`.gitattributes` 已强制），用 Windows 记事本另存为 CRLF 会导致模块无法加载。

**不要上传**：`keystore/`（签名私钥）、`dist/`（APK 走 Release 附件）、`.gradle/`、`build/`、`local.properties`。

## 三、创建 Release

- Tag：`v1.0.0`（指向默认分支最新提交）
- 标题：`AutoSuperSaver v1.0.0`
- 正文：复制 `docs/Release-Notes-v1.0.0.md` 的内容
- 附件：
  - `dist/AutoSuperSaver-1.0.0-release.apk`（2.0 MB）
  - `dist/AutoSuperSaver-1.0.0-debug.apk`（2.3 MB）

发布后把 Release 正文里的 `OWNER` 替换成实际用户名。

## 四、发布后自检

1. 仓库首页能正常渲染 README，中文不乱码。
2. `app/src/main/resources/META-INF/xposed/module.prop` 点开是 4 行键值、无多余空行。
3. Release 页面两个 APK 可下载，大小分别约 2.0 MB / 2.3 MB。
4. 从零克隆能构建：
   ```bash
   git clone https://github.com/<用户名>/AutoSuperSaver.git
   cd AutoSuperSaver
   # 写入 local.properties: sdk.dir=<你的 Android SDK 路径>
   ./gradlew assembleRelease
   ```
   仓库不含私钥，未放 keystore 时 `app/build.gradle` 会自动跳过签名配置（产物为 unsigned，用 Android Studio 的默认 debug 签名或自行生成 keystore，命令见 README）。

## 五、命令行方式（本地已有提交，最快）

```bash
cd F:/a插件制作/小米自动超级省电
git branch -M main
git remote add origin https://github.com/<用户名>/AutoSuperSaver.git
git push -u origin main
```

推送后在网页端建 Release 并上传两个 APK。若使用 `gh` CLI：

```bash
gh release create v1.0.0 \
  dist/AutoSuperSaver-1.0.0-release.apk \
  dist/AutoSuperSaver-1.0.0-debug.apk \
  --title "AutoSuperSaver v1.0.0" \
  --notes-file docs/Release-Notes-v1.0.0.md
```
